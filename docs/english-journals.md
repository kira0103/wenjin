# 论文投稿管理 · 期刊库

“论文投稿管理”内有两个期刊库标签，共用同一份论文与投稿记录：

- **中文C刊库**：CSSCI 2025–2026 目录（C 刊 + C 扩），支持名称/备注搜索、学科与等级筛选、收藏、有投稿地址筛选、按学科/等级分组，以及单卡编辑与 CSV 追加导入。
- **英文期刊库**：约 2.3 万本英文期刊的列表，同时给出 JCR、中科院、新锐三个体系的分区与 Top 信息，支持按学科和分区阈值筛选。

## 英文期刊库

### 数据口径

| 体系 | 版本 | 说明 |
| --- | --- | --- |
| JCR | 2025 版（2026 年 6 月发布） | IF 与四分位（Q1–Q4）。一本刊可能属于多个 WoS 学科，列表展示“最佳四分位”，展开行可看全部学科分区 |
| 中科院 | 2025 版 | 中科院期刊分区表升级版（大类分区 + 小类 + Top）。这是最后一版由中科院文献情报中心发布的官方分区 |
| 新锐 | 2026 版（2026 年 3 月发布） | 新锐期刊分区表（大类 + 小类 + Top）；预警名单已并入，预警刊标记 `Under Review` |

三套体系口径不同、结果可能不一致（例如某刊中科院 2 区但新锐 3 区），这是正常的，页面按列并排展示，不做统一。

### 筛选与展示

- 学科按**中科院大类**过滤（未进入中科院分区的期刊归入“未收录中科院分区”）。
- “n 区及以上”分别作用于 JCR（Qn）与中科院/新锐（n 区）；无分区的记录在设置阈值后被排除。
- 可只看中科院 Top 或新锐 Top；可按 IF、中科院分区、JCR 分区、新锐分区或刊名排序。
- 列表分页（20/50/100 条每页）；点行或“详情”展开中科院小类、新锐小类、JCR 学科明细与其它标注。

### 数据文件与更新

数据文件为 `backend/data/english_journals.json.gz`（约 1.6 MB）。它体积较大且来自第三方数据源，按仓库边界由 `.gitignore` 排除，**不提交仓库**；缺失时英文期刊库提示“数据缺失”，不影响其它功能。打包时由 `package.json` 中的 `--add-data "backend/data;backend/data"` 带入安装包。

更新 JCR / 中科院 / 新锐数据时：

1. 从 [ShowJCR](https://github.com/hitfyd/ShowJCR) 发行包或仓库取得最新的 `jcr.db`（其中包含 `FQBJCR2025`、`JCR2025`、`XR2026` 等表）。
2. 重新生成数据文件：

   ```powershell
   python scripts\build_english_journals.py --db D:\ShowJCR\jcr.db
   ```

3. 重新构建并打包（`npm run build:ui`、`npm run build:backend`、`npm run dist:candidate`）。

生成脚本按刊名归一化后合并三张表；JCR 取 `IF Quartile(2025)_1` 为最佳分区，中科院取大类分区，新锐取大类新锐分区。若上游年份表名变化（如 `FQBJCR2026`、`JCR2026`、`XR2027`），需同步调整脚本中的表名。

### 许可与引用

- ShowJCR 代码为 GPL-3.0；JCR 数据为 Clarivate 版权数据，新锐与中科院分区各有使用条款。本数据仅用于个人本地检索，请勿随软件分发或公开再发布；对外发布前应自行核实数据授权。
- 分区与 IF 仅作投稿参考，投稿前请核对期刊当前收录状态、预警与投稿要求。
